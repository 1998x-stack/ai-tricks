## 原始细节（保留 Wiki 归因）

- **来源**: BugBuster喵
- **适用场景**: 大模型微调、数据构建
- **原文**: "这几年大模型很火，很多人有个误解，以为模型越强，数据就不重要了。实际正相反。模型越强，数据质量对最终效果的影响越明显。差数据会让强模型学得更快，也错得更自信。"
- **要点**: 强模型会更快地从数据中学习模式，如果数据存在噪声或不一致，错误也会被快速放大。数据质量是大模型微调的基石。
- **参见**: [[data-quality]], [[sft]]

## 解释边界

真实数据完整训练的待执行协议，未产生训练结论。所列数值是预注册对照，不代表作者经验在所有模型上成立。最终数据/模型适配与驱动必须经核对，禁止以通用分类任务代替专门任务。
