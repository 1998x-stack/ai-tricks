## 操作与产物

```bash
python experiments/llm-sft/llm-sft-007-01/experiment.py --plan
# 下行仅可在已配置的远程机器执行
python experiments/llm-sft/llm-sft-007-01/experiment.py --run --environment remote.json
```

默认 17、42、2026 三个配对种子，A/B 交替顺序。每组独立重建模型与优化器，
只按验证集选择 checkpoint，最后用共同且锁定的测试集评价。
训练产生每步 loss、验证指标、耗时、显存、预测结果、checkpoint 清单及原始日志；
完整六次运行后生成配对差值表、bootstrap 描述区间、PNG/SVG 曲线。
不要用测试集选参数、丢弃负结果、补造日志或把未实现的干预静默忽略。

## 原始细节（保留 Wiki 归因）

- **来源**: Tang AI
- **适用场景**: 多任务/多领域 SFT 数据量决策
- **原文**: "对于多任务问题，可能有的同学会问到底多少条数据才合理，个人经验，每个垂域400条高质量数据足矣。"
- **要点**: 对于每个垂直领域，大约 400 条高质量标注数据就足够让模型学会该领域的回答范式。关键在"高质量"——宁可 400 条精标，不要 4000 条脏数据。
- **参见**: [[../data-eval/data-eval]]

## 解释边界

真实数据完整训练的待执行协议，未产生训练结论。所列数值是预注册对照，不代表作者经验在所有模型上成立。最终数据/模型适配与驱动必须经核对，禁止以通用分类任务代替专门任务。400 条只是预注册对照样本量，不是普适充分样本定理。
