## 原始细节（保留 Wiki 归因）

- **来源**: 知乎社区
- **适用场景**: 工程实践
- **原文**: "很多人一看效果不行就加层、改 attention、改激活函数、换 loss。大多数业务场景里，这些不是第一优先级。先用成熟结构，先把数据、学习率、训练流程做好。"
- **要点**: 业务调参的优先级：数据质量 → 学习率 → 训练流程 → 网络结构。改激活函数属于结构创新，应在基础工作做好之后考虑。
