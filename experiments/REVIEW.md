# 自审与复核记录

本轮检查针对实验有效性、实现边界、知识正确性及可复现性。所有自动检查均为本机离线合同测试或 CPU 张量夹具；没有下载真实模型权重或 Hugging Face 数据，没有执行完整 GPU 训练。

## 已修复的问题

| 问题 | 修复 | 回归证据 |
|---|---|---|
| gamma / warmup / min_lr 在常量调度下可能不生效 | 显式固定依赖调度；拒绝无效轴 | 比较完整学习率序列，而不只比较 JSON |
| beta 在 SGD 下被静默忽略 | 固定 Adam；启动前检查依赖 | 无效参数组合必须报错 |
| SFT 的 assistant mask 干预会同时改变验证目标 | 验证目标固定为 assistant 回复 token | 两组 evaluation_config 完全相同 |
| 按 step 评估使不同 batch 的样本预算不可比 | 用累计样本数触发评估，并保留末次记录 | 阈值、尾批、非重复最终评估测试 |
| default 初始化被误实现为 Kaiming normal | 保留 PyTorch 层构造器初始化 | 固定种子下与显式 He 的差异测试 |
| 中断数据流仍可能报告完整 epoch | 核对实际训练样本数与计划数 | 截断 epoch 拒绝测试 |
| 无效种子、范围、selector 到训练后才失败 | 本地预检两组配置、范围及切分 | 边界值和两臂校验测试 |
| checkpoint / history 的步数缺少关联 | 校验选择步、最终步及严格递增 | 结果合同检查 |
| 条目移动导致实验 ID 错配风险 | 固定来源路径/标题到稳定编号 | 517 项生成后来源、邻接 JSON、计划审计 |
| 梯度累积忽略变长 token / 尾批 | 重写 Wiki，按有效样本/有效 token 归一化 | 直接执行 Wiki 示例，与大 batch 梯度比对 |
| 随机标签必然无法拟合等错误知识 | 区分记忆与泛化；明确固定随机标签 | 对照一手论文，保留原作者原文与编辑解释 |
| He 方差、标准差与默认初始化混淆 | 明确二阶矩、fan、负斜率与 std | 数学说明和 CPU 初始化测试 |

## 检查命令

```bash
python -m unittest discover -s tests -v
python -m experiments.tools.audit
python tools/build_site.py --output .site-preview/ai-tricks
python site/browser_checks.py --root .site-preview
```

依赖与网站验收见 [站点维护文档](../site/README.md)。张量语义测试需要 torch；CI 显式安装 CPU torch，避免这些测试被跳过。本机无 torch 时会报告 skip，不能将 skip 写成验证通过。
